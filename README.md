# 國語自學 Taiwan Mandarin Self-Study

A free static web app for self-study of Taiwan Mandarin (國語): Traditional characters, Zhuyin first, MOE (教育部)
readings and Taiwan vocabulary. It works offline on a phone and a laptop once visited (PWA).

**Live site:** https://ameriwan.github.io/mandarin-study/ (GitHub Pages serves the `docs/` folder).

## What is in it

| Page | What it does |
|---|---|
| 今天 Today | the daily routine from the plan: a timed pronunciation session (listening ID, tone-pair ID, pitch mirror, shadowing), the current unit, shadowing, review, Anki checkbox, outside-time log |
| 注音 Zhuyin Lab | the 37 symbols with MOE handbook audio, every syllable in every tone (MOE human voice), contrast drills, dictation on the standard Zhuyin keyboard, mouth guides |
| 聲調 Tone Gym | tone basics (Taiwan targets, T3 taught low), tone ID with a confusion matrix, tone pairs, the pitch mirror (your pitch curve over the model's), sandhi, Taiwan readings |
| 跟讀 Shadowing | guided shadowing protocol, sentence bank, MOE dictionary readings with loopable segments, native-speaker check, weekly dose |
| 課程 Units | 16 units for TBCL levels 1–2 set in Pingtung daily life (dialogue, vocab, grammar, pronunciation focus, shadowing, quiz, speaking and writing tasks) |
| 資料庫 Library | TBCL level 1–4 words, grammar levels 1–3, patterns, measure words, Taiwan vs Mainland, phrasebook, 成語, radicals, my notes and mistakes; search by characters, Zhuyin (with or without tones), pinyin or English |
| 計畫 Plan | roadmap (TBCL / TOCFL), hours and pace, placement check, level checks |
| 進階 Advanced | reading and listening ladders, grammar depth, characters, writing and speaking output, register and idioms, TOCFL prep |
| 設定 Settings | display options, immersion mode, voice and speed, mic test, export / import / reset, credits and licenses |

`MASTER_PROMPT.md` is the full specification; `PROGRESS.md` logs every milestone.

## Layout

```
content/   hand-written source data (units, grammar, drills, readings) — edit these
tools/     build.py (content → docs/data, audio, contours), verify.py (MOE Zhuyin check), tests
docs/      the site; docs/data and docs/audio are GENERATED by the build
.cache/    downloaded MOE / TBCL / CC-CEDICT data (gitignored, never committed)
progress/  your progress exports for WEEKLY (gitignored)
```

## Build

```
.venv\Scripts\python.exe tools\fetch.py      # first time: download the reference data into .cache
.venv\Scripts\python.exe tools\build.py      # verify content, build data and audio
```

Useful options: `--max-new N` (download at most N new MOE clips this run), `--max-tts N`, `--no-audio`, `--no-contours`.
Tests: `tools\test_verify.py`, `tools\test_spoken.py`, `tools\test_library.py`. `tools\check_links.py` re-tests the
external links.

Every Zhuyin string in `content/` is checked against TBCL and the MOE dictionaries; the build fails on any mismatch and
`build-report.md` lists warnings, audio coverage and size. Preview locally with
`python -m http.server 8782 --directory docs` and open http://localhost:8782.

`update-site.cmd` builds, commits and pushes in one step.

## Audio honesty

Tone and syllable drills use only MOE human recordings (`MOE` badge). Full sentences use Google TTS (`TTS` badge) or,
offline, the browser's own voice (labelled). MOE recordings are published whole and only their headword span is
played, as the CC BY-ND license requires.
